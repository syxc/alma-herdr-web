# 界面与交互

界面采用 Alma 手机客户端的深色配色与控件布局，包含登录、终端列表和终端详情三种视图。

## 页面与导航

| 视图 | 入口与行为                                                                |
| ---- | ------------------------------------------------------------------------- |
| 登录 | 本机 API 要求口令时显示，登录成功进入会话列表                             |
| 列表 | 按 Working、Blocked、Settled 分组，点终端进入详情；分组折叠状态保存在本地 |
| 详情 | 显示所选面板的终端、状态、标签切换器、操作菜单与输入区                    |

760px 是窄屏断点。窄屏的会话树使用抽屉，选择面板或点击遮罩后关闭；宽屏使用侧栏，可手动收起。静态站点的宽屏布局默认收起侧栏，首次打开显示配对入口。已配对标签页刷新后可恢复所选终端。

列表返回键在本地模式退出登录，在静态站点展开配对入口。详情返回键进入列表。菜单与抽屉由 Escape 逐层关闭。

## 视觉参数

颜色集中在 `web/style.css` 的 `:root` 中，Canvas 使用相同的背景和默认字色。

| 用途        | 色值                  |
| ----------- | --------------------- |
| 页面背景    | `#282C35`             |
| 浮层背景    | `#25282D`             |
| 分隔线      | `#3D414A`             |
| 控件描边    | `#3D4351` / `#454C5A` |
| 正文        | `#DADEE3`             |
| 次文字      | `#9DA2AE`             |
| 弱文字      | `#848891`             |
| 强调蓝      | `#62AFEC`             |
| 蓝底符号    | `#16232F`             |
| 警告 / 危险 | `#E0A458` / `#E05252` |

页面使用系统字体，终端使用系统等宽字体和按需图标回退。终端默认字号 14px，行高为字号的 1.35 倍取整，即 19px。顶栏水平内边距 19px，返回按钮 50px，右侧控件使用圆形或胶囊描边。

列表行显示终端序号、工作目录或 agent 标题，以及状态点。副标题过长时省略。详情菜单包含三种显示方式、面板尺寸、Restart <agent> 和 Restart & Continue；没有可续跑会话时禁用后者。

## 输入

命令框是终端的输入面，字符与控制键直接送到面板，输出由终端画面回显。回车发送 `enter` 并清空本地输入行，上下方向键读取远端历史后也清空本地行。

桌面端打开面板时聚焦 Canvas，直接接收物理键盘。手机点击终端或键盘按钮时聚焦输入框，唤起系统键盘。按键行提供 esc、反引号、Ctrl+C、Tab、Shift+Tab 与方向键，可横向滚动；左侧命令按钮切换按键行可见性。

`TerminalInput` 维护本地编辑状态，`KeyQueue` 按 16ms 窗口合并相邻文字或按键。API 再按请求顺序串行发送，防止网络处理乱序。切换面板前先发送原面板的待发队列，避免把输入送到新面板。

herdr 0.9.5 支持 enter、esc、backspace、tab、方向键、f1 至 f12 及 ctrl/alt/shift 组合。Home/End 映射为 ctrl+a/ctrl+e；Delete 不映射为 ctrl+d，以免触发 EOF。浏览器快捷键保留给浏览器。中文组合输入应在候选提交时发送文本。

## 渲染与滚动

`pane.read` 返回带 SGR 样式的屏幕快照。Ghostty VT 将其转换为单元格，正确保留宽字符的尾列、颜色和样式；`TerminalView` 绘制 Canvas。WASM 尚未就绪或不可用时使用 SGR 解析回退。

| 模式           | 行为                                                 |
| -------------- | ---------------------------------------------------- |
| Wrap to Phone  | 正常字号，按可用列宽重排；合并终端续行并保留悬挂缩进 |
| Original Width | 正常字号，保留面板列宽，允许横向滚动                 |
| Shrink to Fit  | 整体缩放至视口宽度                                   |

窄屏默认 Wrap to Phone，宽屏默认 Original Width，选择保存在 `localStorage`。分隔线裁到屏宽，不折成多条。重排发生在客户端，因为 `pane.read` 不支持按手机宽度重新渲染桌面程序。

读取保留最近约 120 行。视图在底部时跟随输出，读者向上滚动后暂停跟随，以顶部可见行的文字和偏移恢复阅读位置；滚动停止后吸附到整行。会话列表仅在可见元数据变化时重建，避免轮询替换手指下的行。

Nerd Font 图标与额外播放符号只加载当前画面需要的分包，字体完成加载后重绘静止画面。请求失败会延迟重试，不要求终端产生新输出。资源和重建方法见[第三方资源](third-party.md)。

## 验收

构建后运行 `npm test` 与 `npm run privacy-check`。界面改动还需检查以下实际行为：

- 在手机视口检查列表、详情与浮层，确认顶栏、按键行和输入区可操作。
- Wrap 模式保持正常字号且无终端横向溢出；Original 可横向滚动；Shrink 完整显示面板宽度。
- 中文、宽字符与图标不重叠，字体晚加载后能在无新输出时补绘。
- 向上滚动后等待两轮更新，阅读位置不跳回底部；回到底部后继续跟随。
- 连续输入、退格、方向键和面板切换保持目标与顺序，浏览器快捷键仍可用。
- 在真机测试软键盘、中文候选确认、键盘遮挡和滚动；模拟窄屏不能替代这些检查。
- 配对后刷新、断线再恢复与 Forget paired desktop 均按预期工作。

字体与断线恢复的浏览器检查入口见 [README](../README.md#开发与检查)。
