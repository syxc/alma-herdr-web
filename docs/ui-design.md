# 界面与交互

界面沿用 Alma Android 客户端的配色与控件布局，包含登录、终端列表和终端详情三种视图。Web 端定位为手机上的远程终端：优先保证已有会话的查看、切换、实时输入、滚动阅读和断线恢复；工作区创建、目录管理、环境配置和完整桌面管理不在范围内。

## 页面与导航

| 视图 | 入口与行为                                                                                     |
| ---- | ---------------------------------------------------------------------------------------------- |
| 登录 | 本机配置访问口令且会话无效时显示，解锁后进入会话列表                                           |
| 列表 | 按 Working、Needs input、Settled 和中性 Terminals 分组，点终端进入详情；分组折叠状态保存在本地 |
| 详情 | 显示所选面板的终端、状态、标签切换器、操作菜单与输入区                                         |

- 760px 是窄屏断点。多个终端时详情顶栏左侧提供会话树开关：窄屏用抽屉，宽屏用侧栏；只有一个终端时隐藏侧栏与切换器，使用普通编号。
- 顶栏标题相对整条导航栏水平、垂直居中，左右预留等宽区域；详情的编号与副标题整体垂直居中，长标题省略。侧栏面板行只显示名称，不重复 Pane 前缀。
- 静态站未配对时显示 Connect to your herdr 欢迎页，连接区最大宽度 464px。链接输入与 Connect 等高，以 or 分隔全宽扫码入口，均为 48px 高；初始不聚焦，空输入禁用，Enter 提交，连接中防重复。连接后显示 Terminals，忘记配对后返回欢迎页。
- 连接状态用语义色：已连接绿、连接中/重连琥珀、失败/离线红、未配对中性；明暗主题分别适配。连接成功后收起顶部说明与底部重复提示。
- 启动先检查本机访问要求，失败可重试，不预先显示口令表单或误判认证状态。静态站直接配对；免口令本机直接进入列表；有口令本机仅通过 Sign out 菜单退出。有效会话刷新保留，失效后重新解锁。连接成功后列表与详情均无返回箭头，Escape 逐层关闭菜单并恢复焦点。
- Share this desktop 位于列表更多菜单，仅本机 API 且未连接远端时提供；静态站与远端页面不显示。列表右上角 `+` 是唯一创建入口，依次选择 Agent 与已有工作区，支持键盘导航，未配对或无工作区时隐藏。
- 新标签按工作区标签顺序继承首个有目录的面板目录，无可继承目录时传 `~` 由电脑端解析；本机 agent 创建前校验目录真实存在且可读可进入。创建传 `focus:false`，不移动电脑端焦点。shell 初始化只对 `agent_pane_busy` 每 250ms 重试（最多 20 次），其他错误立即提示；启动失败仍进入已建终端。

## 视觉参数

Appearance 提供 System、Light、Dark，默认跟随系统，选择保存在本地；首屏在样式加载前解析偏好，页面、控件、浮层、主题色与 Canvas 同步切换并保留阅读位置。UI 颜色集中在 `web/style.css`，终端默认色与 ANSI 16 色来自 Alma 4.3 Android 的 TerminalScheme（`web/src/terminal-theme.ts`）；快照中固定的黑白灰文字与中性底色随主题适配，彩色 RGB 保持原样。

| 用途               | 深色      | 浅色      |
| ------------------ | --------- | --------- |
| 页面与终端背景     | `#282C34` | `#FFFFFF` |
| 正文与终端默认字色 | `#DCDFE4` | `#1A1A1A` |
| 浮层背景           | `#25282D` | `#F8FAFC` |
| 分隔线             | `#3D414A` | `#C9CDD3` |
| 强调填充           | `#61AFEF` | `#7299A0` |

浅色强调文字用 `#426970` 保持对比度。

- 系统字体；终端系统等宽字体，默认 13px、行高 20px。顶栏水平内边距 19px，窄屏高 58px、宽屏 70px。操作按钮 38 × 38px 圆形底框，触摸区域不小于 44px；控件圆角 10px，浮层 16px。
- 页面标题 18px、菜单主项 15px、辅助说明 12–13px；终端输入框 14px，原生字段 16px 避免聚焦缩放。
- 状态点仅在连接有效、有 Agent 且上游明确报告 working、blocked 或 done 时显示（Working / Needs input / Done）；unknown、idle、exited、无 Agent 和离线均隐藏，不推断运行状态。
- 交互控件关闭默认触摸高亮；悬停只在精确指针设备启用；反馈过渡 120ms，减少动态效果时取消。菜单跟随所属顶栏，终端切换菜单与切换按钮水平居中、左右至少 12px 留白；长标题省略，菜单说明允许换行。

列表行显示终端序号、工作目录或 agent 标题、状态点。自动兼容和 Alma 的 core 地址为 `hc:t1` 或 `hc:machine/t1`；列表去掉来源前缀后识别机器，在目录前显示 This computer 或机器名，完整地址仍作为选择目标，同目录同编号不合并。列表序号与详情顶部数字共用按 `snapshot.panes` 原始顺序生成的连续编号，不受状态分组、Agent 启停或 `tab.number` 空缺影响。选中背景为铺满行宽的直边色带。

工作区树按 Workspace → Tab → Pane 分层，保留后端名称与顺序；工作区标题带标签数量，标签为次级标题，面板为主要选择项。仅面板显示可信状态点，工作区与标签不聚合状态。工作区右侧 44px 按钮控制折叠，标记 `aria-expanded` / `aria-controls`；折叠状态保存在页面内存。选择项均为原生按钮，高至少 44px，支持 Enter / Space，长名称省略并保留完整提示。

连接中或离线时禁用输入、终端选择和 Agent 操作，并隐藏不可靠的运行状态；切换或移除面板立即清理旧画面，旧请求不能覆盖新选择，最后一个面板消失时回到列表。

## 输入

命令框是终端的输入面，字符与控制键直接送到面板，输出由终端画面回显。回车发送 `enter` 并清空本地输入行，上下方向键读取远端历史后也清空。桌面端聚焦原生文本层（Canvas 回退时聚焦画布），手机点击终端或键盘按钮时聚焦输入框唤起系统键盘。

- 底部按键行开关在输入框左侧、回车在右侧，均使用 20px 线性 SVG 图标与 44px 触摸区域。输入框默认只显示单行或占位文字，启用修饰键时才显示 Ctrl / Shift / Alt 状态。
- 快捷栏依次显示 Ctrl、Esc、反引号、Ctrl+C、Shift+Tab、Tab、方向键、退格、Paste；Ctrl 为一次性修饰键。Ctrl+W 删词、Ctrl+U 删到行首放入自选列表，右侧 `+` 可添加行首/行尾、Shift、Alt 等；偏好保存在本地。Paste 仅在点击后读剪贴板，切换面板后丢弃未完成的旧粘贴。
- `TerminalInput` 维护本地编辑，`KeyQueue` 按 16ms 窗口合并相邻输入，API 再按请求顺序串行发送。切换面板前先发送原面板待发队列。
- herdr 0.9.5 支持 enter、esc、backspace、tab、方向键、f1–f12 及 ctrl/alt/shift 组合。Home/End 映射 ctrl+a/ctrl+e，Delete 不映射 ctrl+d 以免触发 EOF。有选区时 Cmd+C / Ctrl+C 复制，无选区时 Ctrl+C 中断远端；输入框的 Ctrl+A 发送行首控制键。补充平面字符编辑保持代理对完整；中文组合输入在 `compositionend` 同步已确认文本并去重，组合确认键不提交命令。

## 渲染与滚动

TUI/Alma 通过 `pane.read source=recent_unwrapped` 读取带 SGR 样式的逻辑行，core 原生 VT 按实际尺寸重放。Ghostty VT 在 Unicode 字素模式下转换为单元格，保留组合 emoji、宽字符尾列、颜色与样式；`TerminalView` 由单元格生成原生文本段，Canvas 回退按行合并连续同色底色。中性消息底色按主题适配，饱和彩色 ANSI 背景保留；中性表面上的文字保持至少 4.5:1 对比。每次重放前复位 SGR；WASM 未就绪时先显示按字素解析的 SGR 回退，加载完成立即应用最新快照。相同文本与行列数跳过解析重绘。

| 模式           | 行为                                                 |
| -------------- | ---------------------------------------------------- |
| Wrap to Phone  | 正常字号，按可用列宽重排；合并终端续行并保留悬挂缩进 |
| Original Width | 正常字号，保留面板列宽，允许横向滚动                 |
| Shrink to Fit  | 整体缩放至视口宽度                                   |

默认 Wrap to Phone，按实际可用宽度重排，选择保存在 `localStorage`。Shrink 只缩小超宽内容、不放大窄内容；Wrap 可将来源端手动分行的连续中文正文重排到更宽页面。重排保持宽字与尾格成对，保留背景色、反色、下划线空格、段落空行、代码缩进与表格对齐空格；中文采用字间断点并避开行首结束标点与行尾开始括号。深缩进超出手机宽度时缩短缩进，分隔线裁到屏宽。

- 只在终端详情可见时读取最近 120 行，到顶且后端报告截断时逐步扩大范围（TUI 单次上限 1000 行）。pi 应用历史不在回滚区：识别提示行与状态栏后拼接多屏为连续文档，只保留最新一份提示与状态栏；预载期间不显示中间翻页画面，结束或取消时通过 Ctrl+End 返回实时位置。
- 视图在底部时跟随输出，向上滚动后暂停跟随，以源行文字与字符列恢复阅读位置；改变宽度或显示模式仍保留同一源字符。滚动沿用浏览器原生偏移与惯性，停止后不吸附到整行。
- 触摸接触期间暂停快照重放与重排，手指全部离开且连续 120ms 无滚轮及滚动事件后再恢复，避免阻断惯性；阅读期间仅保留最新一份快照。
- 原生文本层与复制共用文本节点；Canvas 只用于测量、键盘焦点与无原生文本层时的回退，回退绘制使用最多三屏缓存。完整 VT 快照独立重放，复用未变源行，只合并样式一致且源偏移连续的 ASCII 字符。
- 选择期间不替换文本节点或重绘所选画面，清除选区后恢复最新内容；相同快照不更新 DOM，滚动不重建文本层。有选区时 Escape 只清除选区，不向远端发送按键。复制按原始单元格位置提取纯文本，去除 ANSI、宽字尾格与仅供重排的换行缩进，保留源换行、段落空行与代码空格。
- Nerd Font 图标与播放符号只加载当前画面需要的分包，加载完成后重绘静止画面；失败延迟重试，不要求终端产生新输出。维护方法见[第三方资源](third-party.md)。

## 验收

构建后运行 `npm test` 与 `npm run privacy-check`。界面改动还需检查：

- 手机视口下顶栏、按键行、输入区与浮层可操作；深浅主题与 320、390、1024px 下无横向溢出，末项可滚动到达。
- 工作区树保留名称、数量、顺序、状态和分屏归属；三层选择入口与当前项提示正确。
- 列表 `+` 沿用目录创建后进入新面板，不移动电脑端焦点；检查重复点击、启动失败、空工作区与菜单关闭。
- 新建 pi 后退出回到 shell，面板身份与顶部编号保持不变；编号与列表一致，后端标签编号有空缺或状态分组变化时亦如此。
- System / Light / Dark 与刷新后的偏好、阅读位置；固定中性文字随主题变化，彩色 RGB 高亮不变。
- Wrap 无横向溢出、Original 可横向滚动、Shrink 完整显示面板宽度；用 240 列超宽内容确认三者差异，70 列与宽窗口确认不会无故放大。
- 中文、宽字符、组合 emoji 与图标不重叠；字体晚加载后无新输出也能补绘；WASM 加载前后字素与占列一致。
- 改变宽度、显示模式或更新快照后保留阅读源字符；长快照可滚到首尾，原生显示长距离触摸滑动中 Canvas 绘字与换区为零。
- 受控 `pointerdown` / `pointercancel` 复核滑动接管前后不回拉、不额外重绘；慢拖动停顿中收到更新仍不重放，松手惯性停止后应用最新快照。
- 向上滚动后阅读位置不跳回底部；停滚后恢复最新快照，切换面板不补回旧内容，回到底部继续跟随。
- 选择并复制中英文、emoji、多行代码，三种模式下无 ANSI、无重排折行且保留源空格；有选区时 Ctrl+C 不发送远端中断，Escape 清除选区。
- 相同快照零 DOM 更新；三种模式及明暗主题下局部绘制与完整重绘逐像素一致；追加、前插、中间修改后复制偏移正确。
- 连续输入、退格、方向键和面板切换保持目标与顺序；浏览器快捷键仍可用。
- 在真机测试软键盘、中文候选确认、键盘遮挡与滚动，模拟窄屏不能替代。
- 配对后刷新、断线再恢复与 Forget paired herdr；静态站与免口令本机无登录闪现或退出入口；有口令本机检查错误口令、解锁、刷新恢复、会话失效与退出菜单。

字体与断线恢复的浏览器检查入口见 [README](../README.md#开发与检查)。
