# 界面与交互

界面沿用 Alma Android 客户端的配色与控件布局，包含登录、终端列表和终端详情三种视图。

## 页面与导航

| 视图 | 入口与行为                                                                |
| ---- | ------------------------------------------------------------------------- |
| 登录 | 本机 API 要求口令时显示，登录成功进入会话列表                             |
| 列表 | 按 Working、Blocked、Settled 分组，点终端进入详情；分组折叠状态保存在本地 |
| 详情 | 显示所选面板的终端、状态、标签切换器、操作菜单与输入区                    |

760px 是窄屏断点。窄屏的会话树使用抽屉，选择面板或点击遮罩后关闭；宽屏使用侧栏，可手动收起。静态站点的宽屏布局默认收起侧栏，首次打开显示配对入口。已配对标签页刷新后可恢复所选终端。

连接成功后收起顶部说明和底部重复提示，连接详情可从列表与详情的更多菜单查看；连接中、断线重连和错误继续直接显示。

列表返回键在本地模式退出登录，在静态站点展开配对入口。详情返回键进入列表。菜单与抽屉由 Escape 逐层关闭。

列表右上角 `+` 打开 New Tab 菜单，先选 Claude Code、Codex 或 pi，再从工作区列表选择目标。新标签沿用该工作区首个标签的首个面板目录；没有目录时交由电脑端使用默认目录。创建使用 `focus:false`，取得新面板后启动所选 Agent，并在当前浏览器进入该终端，电脑端焦点不变。创建期间禁用重复操作；新面板虽已出现在状态中，其 shell 仍可能初始化，仅对 `agent_pane_busy` 每 250ms 重试启动，最多 20 次，沿用同一个面板且不重复创建标签。连接切换后停止重试，其他错误立即提示；Agent 启动失败仍打开已建终端并显示错误。没有工作区或连接不可用时禁用 `+`。菜单支持方向键、Enter、返回和 Escape；点外部或打开更多菜单时关闭。更多菜单的 New workspace 为独立入口。

## 视觉参数

登录页和列表、详情菜单提供 Appearance：System、Light、Dark，默认跟随系统，选择在本地保存。原生选择器保留系统选项菜单，箭头独立预留空间，触摸高度为 44px。系统外观变化即时生效，首屏在样式加载前解析偏好。页面、输入控件、浮层、浏览器主题色和 Canvas 同步切换；切换时保留阅读位置。

UI 颜色集中在 `web/style.css`；终端默认色和 ANSI 16 色来自 Alma 4.3 Android 内置 TerminalScheme，定义在 `web/src/terminal-theme.ts`。快照中固定的黑白灰文字和中性底色也随页面外观适配，避免浅色程序在暗色页面中仍显示黑字浅底；低对比度中性文字采用当前主题的正文或辅助色。彩色 RGB、彩色背景和黑底彩字的标志配色保持原样，反色在适配后应用。当前使用 Alma 内置终端配色，尚未同步电脑自定义主题。

| 用途               | 深色      | 浅色      |
| ------------------ | --------- | --------- |
| 页面与终端背景     | `#282C34` | `#FFFFFF` |
| 正文与终端默认字色 | `#DCDFE4` | `#1A1A1A` |
| 浮层背景           | `#25282D` | `#F8FAFC` |
| 分隔线             | `#3D414A` | `#C9CDD3` |
| 强调填充           | `#61AFEF` | `#7299A0` |

浅色强调文字使用 `#426970` 保持对比度。

页面使用系统字体，终端使用系统等宽字体和按需图标回退。终端默认字号 14px，行高为字号的 1.5 倍，即 21px。顶栏水平内边距 19px，高度在窄屏固定为 58px、宽屏固定为 70px。列表页与详情页的操作按钮共用 38 × 38px 圆形底框，右侧采用一致的两列布局；切换页面时按钮中心坐标保持一致。返回与会话按钮保留 50 × 50px 触摸区域，更多与新建按钮保留 60 × 46px 触摸区域。焦点轮廓沿可见圆形底框绘制。控件共用 1px 的柔和焦点线；原生选择器和输入卡片只改变现有边框颜色，不叠加第二圈描边或光晕，键盘焦点保持可辨认。

普通控件圆角为 10px，浮层圆角为 16px。页面标题 18px、菜单主项 15px、辅助说明 12–13px。圆角矩形按钮和快捷键的可见底框高 36px，触摸高度保留 44px；普通按钮文字 13px、快捷键文字 12px，方向键、加号等符号为 20px。外观选项可见文字 14px，保留透明原生选择器及 44px 操作范围。终端输入框以 14px 显示文字，原生字段保留 16px 避免聚焦缩放；输入提示为 11px，底部圆形操作底框缩至 32px，符号与触摸范围保持。辅助文字统一使用可读的 muted 色，错误文字从原危险色混入正文亮度，基础明暗色板与终端颜色保持不变。状态点分别表达 Working、Blocked 和 Done，不被统一强调色覆盖。

交互控件关闭浏览器默认的触摸高亮，按下反馈绘制在自身圆角或内缩底框上。鼠标悬停只在支持精确指针的设备启用；键盘焦点轮廓和禁用状态保持可辨认。反馈过渡为 120ms，系统要求减少动态效果时取消过渡。菜单跟随所属顶栏定位，在连接提示出现或窄屏文字换行时仍位于按钮下方；长标题使用省略号，菜单说明允许换行。

列表行显示终端序号、工作目录或 agent 标题，以及状态点。列表序号和详情顶部数字共用按 `snapshot.panes` 原始顺序生成的连续编号，不受状态分组、Agent 启停或后端 `tab.number` 空缺影响；面板增删或顺序变化时按新顺序编号。副标题过长时省略。选中背景使用铺满行宽的直边色带，背景裁在分隔线内；分组首行补齐上边线，取消圆角卡片与分隔线重叠的样式。详情菜单包含三种显示方式、面板尺寸、Restart <agent> 和 Restart & Continue；没有可续跑会话时禁用后者。

## 输入

命令框是终端的输入面，字符与控制键直接送到面板，输出由终端画面回显。回车发送 `enter` 并清空本地输入行，上下方向键读取远端历史后也清空本地行。

桌面端打开面板时聚焦 Canvas，直接接收物理键盘。手机点击终端或输入卡片内的键盘按钮时聚焦输入框，唤起系统键盘。底部以双行卡片标明 Real-time input，右侧保留按键行开关和回车按钮。

快捷操作栏默认依次显示 Tab、Esc、Paste、Shift+Tab、历史上/下和 Ctrl+C 七项。Ctrl+W 删词和 Ctrl+U 删到行首放入自选列表。右侧固定的 + 可添加行首/行尾、左右移动、修饰键等额外操作；选项附有用途说明，偏好保存在本地。Shift、Ctrl、Alt 对下一次按键生效，随后释放；开始组合输入或移除修饰键时清除待用状态。Paste 仅在点击后读取剪贴板，失败时提示长按输入框粘贴；切换面板后丢弃尚未完成的旧粘贴。

`TerminalInput` 维护本地编辑状态，`KeyQueue` 按 16ms 窗口合并相邻文字或按键。API 再按请求顺序串行发送，防止网络处理乱序。切换面板前先发送原面板的待发队列，避免把输入送到新面板。

herdr 0.9.5 支持 enter、esc、backspace、tab、方向键、f1 至 f12 及 ctrl/alt/shift 组合。Home/End 映射为 ctrl+a/ctrl+e；Delete 不映射为 ctrl+d，以免触发 EOF。Cmd 组合键保留给浏览器。补充平面字符的退格和左右移动保持代理对完整，中间编辑后保留输入框光标位置。中文组合输入在 `compositionend` 时同步已确认文本，不依赖其后另发普通 `input` 事件；若后续 `input` 到达则按当前编辑状态去重，组合确认键不提交终端命令。

## 渲染与滚动

`pane.read` 返回带 SGR 样式的屏幕快照。Ghostty VT 在 Unicode 字素模式下将其转换为单元格，保留组合 emoji、旗帜、宽字符尾列、颜色和样式；`TerminalView` 先按行合并连续同色底色并绘制，再绘制文字和下划线，避免小数单元格宽度产生接缝。中性消息底色按页面主题适配，彩色 ANSI 背景仍按程序输出保留。每次重放前复位 SGR，避免上一快照的样式泄漏。WASM 未就绪时先显示按字素和宽字占列解析的 SGR 回退，避免中文与 emoji 在加载前重叠或拆开，加载完成立即补绘最新快照；下载超时或失败后可重试。相同文本与面板行数跳过解析和重绘，排版只在内容、宽度或显示模式变化时重算。

| 模式           | 行为                                                 |
| -------------- | ---------------------------------------------------- |
| Wrap to Phone  | 正常字号，按可用列宽重排；合并终端续行并保留悬挂缩进 |
| Original Width | 正常字号，保留面板列宽，允许横向滚动                 |
| Shrink to Fit  | 整体缩放至视口宽度                                   |

窄屏默认 Wrap to Phone，宽屏默认 Original Width，选择保存在 `localStorage`。重排保持宽字与尾格成对，保留背景色、反色和下划线空格；消息行尾的纯填色空格按当前视口补齐，不折成多余空行，同色消息词间的换行分隔空格也不独占一行。长词不超出可用列宽。中文采用字间断点并避开行首结束标点与行尾开始括号，中英混排不会只因前面的空格而过早折行。列表和树形输出按标记识别正文缩进，不依赖英文字母。段落空行、代码缩进和表格对齐空格保留；代码与围栏内容不并入上一段。深缩进超出手机宽度时缩短缩进，为正文留出空间。只对可识别的状态栏压缩字段间长空白，分隔线裁到屏宽，不折成多条。

重排发生在客户端，因为 `pane.read` 不支持按手机宽度重新渲染桌面程序，也不携带软换行标记。客户端合并可识别的列表正文续行；无法区分来源的同缩进行保留源换行，避免误合并独立段落或代码。

只在终端详情可见时读取最近约 120 行快照。列表继续更新会话状态，后台与登录页暂停主动轮询；返回前台时重新读取状态，保留现有连接。视图在底部时跟随输出，读者向上滚动后暂停跟随，以源行文字与字符列恢复阅读位置，连续改变宽度或切换显示模式仍保留同一源字符，用户实际滚动后再更新锚点；滚动停止后吸附到整行。会话列表仅在可见元数据变化时重建，避免轮询替换手指下的行。

完整内容高度由滚动容器内的占位层承载，Canvas 只分配视口高度的像素缓冲并绘制可见行；滚动时按实际偏移重绘，长快照不会创建与全部重排行数等高的画布。文字绘制独立放在 `terminal-painter.ts`，底色合并、宽字下划线与样式顺序保持一致。

Nerd Font 图标与额外播放符号只加载当前画面需要的分包，字体完成加载后重绘静止画面。请求失败会延迟重试，不要求终端产生新输出。资源和重建方法见[第三方资源](third-party.md)。

## 验收

构建后运行 `npm test` 与 `npm run privacy-check`。界面改动还需检查以下实际行为：

- 在手机视口检查列表、详情与浮层，确认顶栏、按键行和输入区可操作。
- 列表 `+` 依次展示 Agent 和工作区，沿用目录，创建后进入返回的新面板；检查重复点击、启动失败、空工作区和菜单关闭，确认不移动电脑端焦点。
- 新建 pi 后退出回到 shell，面板身份和顶部编号保持不变；返回列表再进入，编号与列表一致，后端标签编号有空缺或状态分组变化时亦如此。
- 检查 System、Light、Dark、刷新后的偏好恢复及阅读位置；固定中性文字与底色应同步变化，彩色 RGB 高亮应保持不变。
- Wrap 模式保持正常字号且无终端横向溢出；Original 可横向滚动；Shrink 完整显示面板宽度。
- 中文、宽字符、组合 emoji 与图标不重叠，字体晚加载后能在无新输出时补绘；WASM 加载前后的字素与占列保持一致。
- 中文列表、中英混排、段落空白、代码对齐、深缩进和标点边界在不同宽度下保持可读。
- 连续改变宽度、切换显示模式及更新快照后保留阅读源字符；长快照可滚到首尾，画布缓冲高度不超过视口。
- 向上滚动后等待两轮更新，阅读位置不跳回底部；回到底部后继续跟随。
- 连续输入、退格、方向键和面板切换保持目标与顺序，浏览器快捷键仍可用。
- 在真机测试软键盘、中文候选确认、键盘遮挡和滚动；模拟窄屏不能替代这些检查。
- 配对后刷新、断线再恢复与 Forget paired desktop 均按预期工作。

字体与断线恢复的浏览器检查入口见 [README](../README.md#开发与检查)。
